# 📚 My Own Library

Учебный пет-проект онлайн-библиотеки на **Django** и **Django REST Framework**. Проект создан для закрепления навыков бэкенд-разработки и дальнейшей практики с контейнеризацией в **Docker**.

## 🚀 Что уже реализовано

* **Каталог книг:** отображение карточек с обложками, названиями и авторами в адаптивной сетке (CSS Grid).
* **Поиск:** поиск книг по названию и имени автора (`Q`-объекты, регистронезависимый поиск).
* **Пагинация:** постраничный вывод списка книг с навигацией по страницам.
* **Читалка:** отдельная страница для чтения текста конкретной книги.
* **REST API:** базовые эндпоинты на базе `ModelViewSet` с разделением прав доступа (чтение — для всех, редактирование и добавление — только для администраторов).
* **Кастомная модель пользователя:** заложена базовая структура на основе `AbstractUser` для дальнейшего расширения профиля.

## 🛠 Стек технологий

* **Backend:** Python 3, Django, Django REST Framework
* **Frontend:** HTML5, CSS3 (адаптивная сетка без сторонних фреймворков)
* **База данных:** SQLite (для локальной разработки)
* **Инфраструктура (в процессе обучения):** Docker, Docker Compose

## ⚙️ Запуск проекта локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd my_own_library
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS
   # .venv\Scripts\activate   # Для Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта и добавьте туда ваш секретный ключ:
   ```env
   SECRET_KEY=ваш_секретный_ключ
   DEBUG=True
   ```

5. **Выполните миграции и запустите сервер:**
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   python manage.py runserver
   ```
   После запуска сайт будет доступен по адресу `http://127.0.0`.
